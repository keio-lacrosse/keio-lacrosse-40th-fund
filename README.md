# 創部40周年記念寄付金 特設サイト

公開中のサイト: https://fund.keiolacrosse.com/

このページは、サイトを更新する人のための手順書です。
**パソコンのブラウザだけで更新できます。** 特別なソフトは要りません。

---

## はじめに知っておくこと

- **保存すると、2〜3分で本番のサイトに反映されます。** 下書きの状態はありません
- 書き方に誤りがあると、自動のチェックで公開が止まります。**その場合、サイトは前の版のまま**なので、慌てなくて大丈夫です（→「公開されたか確かめる」）
- 変更はすべて「誰が・いつ・何を変えたか」が記録され、前の版に戻せます
- **このリポジトリは誰でも見られます。** 写真や文章は、消しても履歴に残ります。載せてよいものだけを入れてください
- 口座番号はサイトに載せない決まりです（入れると公開が止まります）

## アカウントについて

**GitHub のアカウントは1人1つ、自分のものを使ってください。** 共有アカウントは GitHub の規約で禁止されています。
アカウントを作ったら、ユーザー名を部門長に伝えてください。編集できるように招待します。

## Voices に1人追加する

### 1. 写真を上げる（写真がある場合）

1. 上の一覧から `photos` → `voices` フォルダを開く
2. 右上の **Add file → Upload files** を押し、写真をドラッグして入れる
3. ファイル名を、ローマ字の **名前-名字** にしておく（例: `kato-taro.jpg`、プレー写真は `kato-taro-2.jpg`）
   - 半角の小文字・数字・ハイフンだけ。アップロード前にパソコン上で名前を変えておくと楽です
4. 下の **Commit changes** を押す

写真の形の目安は [photos/README.md](photos/README.md) にあります。

### 2. 原稿を足す

1. `content` → `voices.json` を開き、右上の **鉛筆マーク（Edit this file）** を押す
2. `"voices": [` の **すぐ下の行** に、次のかたまりを貼り付ける（新しい人が一番上に表示されます）

```json
    {
      "id": "kato-taro",
      "category": "ob",
      "headline": "掲げる言葉（「」は付けない）",
      "meta": "2018年卒 男子部主将",
      "name": "加藤 太郎",
      "sub": "",
      "date": "2026-12-01",
      "photo": "kato-taro",
      "instagram": "",
      "body": [
        "1段落目の文章。",
        "2段落目の文章。"
      ],
      "photo2": "kato-taro-2"
    },
```

3. 中身を書き換える
4. 右上の **Commit changes...** → もう一度 **Commit changes** を押す

| 項目 | 書くこと |
|---|---|
| `id` | ページ内リンクの名前。写真と同じローマ字（半角小文字・数字・ハイフン）。**LINE等で配った後は変えない** |
| `category` | `genneki`（現役）/ `shidou`（指導陣）/ `ob`（OB・OG）のどれか |
| `headline` | 大きく出す一言 |
| `meta` | 肩書（例: `総監督`、`2026年度 女子部主将`） |
| `name` | 氏名。姓と名の間に半角スペース |
| `sub` | 補足（例: `ポジション：DF`）。無ければ `""` のまま |
| `date` | 掲載日。`2026-12-01` の形 |
| `photo` / `photo2` | 上げた写真の名前（`.jpg` は付けない）。写真が無ければ `""` |
| `instagram` | 同じ内容のInstagram投稿のURL。無ければ `""` |
| `body` | 本文。`"` と `"` で挟んだ1つが1段落。段落の間は `,` で区切る |

### 書き方で間違えやすいところ

- **かたまりの最後の `},` のカンマを忘れない**（次の人とのつなぎ目）
- `body` の **最後の段落の後ろにはカンマを付けない**
- `"` は **半角**。Word やメモ帳からコピーすると全角の `”` になることがあります
- 本文の途中で改行したいときは、改行キーではなく `\n` と書く（決め台詞の行を分けたいときだけ）
- 改行の位置（単語の途中で切れないように）は自動で調整されます

## 写真を差し替える（トップページ）

1. `photos` フォルダを開く
2. **Add file → Upload files** で、決まった名前の写真を上げる（例: 一番上の写真なら `hero.jpg`）
3. **Commit changes** を押す

名前の一覧は [photos/README.md](photos/README.md) にあります。
元に戻したいときは、`photos` に上げた写真を削除すると、元の写真に戻ります。

## トップページの文章を直す

1. `site` → `index.html` を開き、鉛筆マークを押す
2. キーボードの **Ctrl + F**（Mac は **⌘ + F**）で、直したい文章を探す
3. **文字だけ** を書き換える。`<` と `>` で囲まれた部分（タグ）には触らない
4. **Commit changes** を押す

```html
<p>この部分の文字だけを書き換える</p>
```

`<br>` は改行、`<b>…</b>` は太字です。消すとそれぞれ改行・太字がなくなるだけで、壊れはしません。

## 新しいページを追加する

**HTMLが書ける人向けです。** 自信がなければ部門長に相談してください。

1. `site` の中に、ページ名のフォルダを作って `index.html` を置く（例: `site/report/index.html` → `https://fund.keiolacrosse.com/report/`）
   - GitHub 上では **Add file → Create new file** で、名前の欄に `report/index.html` と打つとフォルダごと作れます
2. 見た目を揃えるには、`site/index.html` の冒頭にある `<style>` の中身（色・文字の設定）をコピーして使う
3. トップページからリンクを張らないと、誰もたどり着けません

## 公開されたか確かめる

1. 上のメニューの **Actions** を開く
2. 一番上の行の印を見る
   - 🟡 黄色の丸: 作業中（2〜3分待つ）
   - ✅ 緑のチェック: 公開完了。サイトを開いて確認する（古い表示のままなら再読み込み）
   - ❌ 赤のバツ: **公開が止まった**。サイトは前の版のまま
3. 赤のときは、その行 → `build` → 赤くなっている段を開くと、日本語で原因が書いてあります（`[公開を中止しました]` や `[中止]` の行）
4. 直して、もう一度保存すれば公開されます

## 前の版に戻す

1. 戻したいファイルを開き、右上の **History** を押す
2. 戻したい時点の行の右側にある `<>`（その時点のファイルを見る）を押す
3. 中身を全部コピーし、今のファイルの編集画面に貼り付けて保存する

分からなくなったら、触る前に部門長へ連絡してください。

## 中身の構成（管理者向け）

```
content/voices.json   … Voices の原稿
photos/               … 差し替え用の写真（公開時に縮小・位置情報削除して上書き）
site/                 … サイト本体（index.html と写真）
scripts/build_site.py … 公開前の組み立てとチェック（GitHub Actions が実行）
```

`site/voices/` は `voices.json` から自動で作られるので、直接編集しません。
