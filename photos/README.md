# 写真の置き場所

ここに **決まった名前で** 写真を上げると、サイトの同じ名前の写真が差し替わります。
サイズの縮小や位置情報の削除は自動で行うので、スマホの写真をそのまま上げてかまいません。
上げ方は [リポジトリ直下の手順書](../README.md) の「写真を差し替える」を見てください。

**上げた写真は、後で消しても誰でも見られる状態で残ります。** 掲載してよい写真だけを上げてください。

## トップページの写真（このフォルダに置く）

| ファイル名 | 場所 | 形の目安 |
|---|---|---|
| `hero.jpg` | 一番上の大きな背景（上に文字とロゴが乗る） | 横長 |
| `story.jpg` | 創部ストーリー | 縦長 4:5 |
| `mens-01.jpg` | 男子部のプレー（大） | 横長 4:3 |
| `mens-02.jpg` / `mens-03.jpg` | 男子部のプレー（小） | 横長 3:2 |
| `womens-01.jpg` | 女子部のプレー（大） | 横長 4:3 |
| `womens-02.jpg` / `womens-03.jpg` | 女子部のプレー（小） | 横長 3:2 |
| `use-polish.jpg` | 使い道①磨く（練習・トレーニング） | 横長 3:2 |
| `use-fight.jpg` | 使い道②戦う（試合・遠征） | 横長 3:2 |
| `use-support.jpg` | 使い道③支える（テント・運営・応援） | 横長 3:2 |
| `report.jpg` | 報告のセクション | 横長 4:3 |

形が目安と違っても枠からはみ出した分が自動で切れるだけなので、崩れはしません。
ただし、顔が端にあると切れることがあります。**大事なものは真ん中に来るよう、スマホで切り抜いてから上げる**のが確実です。

## Voices の写真（`voices` フォルダに置く）

`voices.json` の `photo` / `photo2` に書いた名前と同じにします。

| ファイル名の例 | 使う場所 | 形の目安 |
|---|---|---|
| `kato-taro.jpg`（`photo` の名前） | 見出しの横・一覧のタイル | 縦長 4:5、顔が上の方に来るように |
| `kato-taro-2.jpg`（`photo2` の名前） | 本文の最後 | 横長 3:2 |

## 使えないもの

- iPhone の HEIC 形式（「写真」アプリから共有すると JPEG になることが多い。だめなら設定→カメラ→フォーマット→「互換性優先」）
- 決まった名前以外のファイル（公開が止まり、エラーで知らせます）
- ロゴ（ロゴの差し替えは部門長に依頼してください）
